# 同桌 · 网页桌游大厅

局域网多人网页桌游，Node.js 18+ 零第三方运行依赖。支持房间邀请、观战、聊天与表情、自动计分、断线重连、机器人、规则教学、桌游币与外观换装。

## 下载与运行

[直接下载最新 ZIP](https://github.com/littleUMR/tongzhuo-board-games/archive/refs/heads/main.zip)，或点击 Code → Download ZIP。解压完整目录。

1. 主机安装 [Node.js 18 或更高版本](https://nodejs.org/)，无需 npm install 或数据库。
2. Windows 双击 `启动桌游.bat`；macOS/Linux 在项目目录执行 `node server.js`。
3. 主机打开 http://localhost:3000 ，朋友使用服务窗口显示的局域网地址。大家需处于同一网络，主机服务窗口需保持开启。
4. 输入昵称，创建或加入房间，准备后由房主开始。

Windows 防火墙提示时允许 Node.js 在专用网络通信。访客 Wi-Fi 或 AP 隔离可能阻止互访。服务面向可信局域网，请勿直接转发到公网。

更换端口：PowerShell 执行 `$env:PORT=3001; node server.js`。

## 游戏与功能

| 游戏 | 人数 | 玩法 |
| --- | --- | --- |
| 卡卡颂 | 2–5 | 基础版地块拼接、随从与区域计分 |
| 印加寻宝 | 3–8 | 同时选择继续或返回、神器、五轮计分与荣誉展示 |
| 大宋百商图 | 2–4 | 菜谱构筑、商铺经营与客人结算的数字改编 |
| 文字麻将 | 2–6 | 十三字成句、吃碰、问答、众议与技能成长 |
| 染域 | 2–8 | 领地染色、战术牌、强化与锚点；游戏提供者 ww |

- 卡卡颂、印加寻宝与大宋百商图支持难度机器人和教学局；其他游戏的功能以大厅入口为准。
- 同桌快捷标记、方向箭头和临时互动动画同步给房间成员。
- 外观扭蛋、纸娃娃换装、入场演出、收藏与印加荣誉称号。
- 染域的 MIT 运行代码及网页随包保存在 `vendor/chroma/`，不依赖作者电脑上的其他目录。

## 存档与隐私

首次运行按需创建 `data/`；染域兼容档案位于 `vendor/chroma/data/`。包含玩家身份、房间、聊天、图片、历史与外观等私人记录。发布包不携带这些数据，分享或备份源码时排除所有 `data/` 目录。对局中请勿清理浏览器本地数据，以免丢失玩家身份。

## 开发与检查

在项目根目录运行 `npm test`。`public/` 为网页与素材，根目录 JavaScript 为服务和规则，`tests/` 为回归测试。`vendor/chroma/` 为染域依赖。发布包不包含本机加工工具、生成原图、验收截图、测试临时目录或依赖缓存。
