# 同桌 · 网页桌游大厅

支持卡卡颂（2–5 人）和印加寻宝（3–8 人）的局域网网页桌游。包含房间邀请、准备与观战、规则说明、自动计分、断线重连、聊天与表情、桌游币奖励。

## 下载与运行

1. 在 GitHub 点击 **Code → Download ZIP**，解压完整目录。
2. 主机安装 Node.js 18 或更高版本：https://nodejs.org/ 。无需 npm install，也无需数据库。
3. Windows 双击 `启动桌游.bat`；其他系统在项目目录执行 `node server.js` 或 `npm start`。
4. 主机打开 http://localhost:3000 ，其他玩家打开服务窗口显示的局域网地址。所有玩家连接同一网络。
5. 输入昵称，创建或加入房间，准备后由房主开始游戏。服务窗口必须保持开启。

Windows 防火墙提示时允许 Node.js 在专用网络通信。访客 Wi-Fi、AP 隔离可能阻止电脑互访。此服务面向可信局域网，请勿直接暴露到公网。

更换端口：PowerShell 执行 `$env:PORT=3001; node server.js`。

## 存档与隐私

首次运行自动创建 `data/`，保存房间、聊天图片、历史对局、身份及桌游币。发布版本不包含任何原玩家数据。对局中请勿清理浏览器本地数据，以免丢失玩家身份。备份或分享项目时排除 `data/`。

## 开发与验证

- `public/`：网页和运行美术资源。
- `server.js`：Node.js HTTP 服务和 SSE 同步。
- `game.js`、`incan.js`：游戏规则与计分。
- `economy.js`：桌游币结算。
- `tests/`：规则、HTTP 多人对局、聊天、重连及界面静态检查。

运行 `npm test`。项目不依赖第三方 Node.js 包。Node.js 18 的测试运行器在较早版本中可能显示实验性提示。

本开源包保留运行代码、美术和测试；不包含本机专用美术加工工具、生成过程原图或验收聊天截图。
